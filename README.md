# Classification Model - SVM (Purchase Propensity)

## 🎯 Objective
This project is part of EBAC's Data Science course (Module 39). The objective is to apply **Support Vector Machine (SVM)** techniques to predict customers' purchase propensity for cars, based on demographic and financial data.

## 🛠️ Technologies Used
- Python 3.9+  
- Pandas, NumPy  
- Scikit-learn (SVC, LabelEncoder, Model Selection)  
- Matplotlib, Seaborn  

## 📊 Methodology
1. **Data Exploration:** Analysis of data types, checking for null values, and removal of the `User ID` column.  
2. **Preprocessing:** Application of `LabelEncoder` to the categorical variable `Gender` to adapt it for the model.  
3. **Analysis:** Creation of a correlation matrix to identify variables with the greatest impact on the target variable (`Purchased`).  
4. **Modeling:** Implementation and training of the SVM classifier (SVC).

# Projeto: Modelo de Classificação - SVM (Propensão de Compra)

## 🎯 Objetivo
Este projeto faz parte do curso de Data Science da EBAC (Módulo 39). O objetivo é aplicar técnicas de **Support Vector Machine (SVM)** para prever a propensão de compra de carros pelos clientes, com base em dados demográficos e financeiros.

## 🛠️ Tecnologias Utilizadas
- Python 3.9+
- Pandas, NumPy
- Scikit-learn (SVC, LabelEncoder, Model Selection)
- Matplotlib, Seaborn

## 📊 Metodologia
1. **Exploração dos dados**: Análise de tipos de dados, verificação de nulos e remoção da coluna `User ID`.
2. **Pré-processamento**: Aplicação de `LabelEncoder` na variável categórica `Gender` para adequação ao modelo.
3. **Análise**: Criação da matriz de correlação para identificar as variáveis com maior impacto na variável target (`Purchased`).
4. **Modelagem**: Implementação e treinamento do classificador SVM (SVC).
